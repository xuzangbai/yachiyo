# 幕间加载动画

在「客户端 → 配置 → 加载动画」中，可以关闭幕间界面、单独静音或调整音量；关闭界面后使用原版加载页。
替换的是启动游戏和重载资源时的加载页，原版资源进度、错误处理、完成回调和退出时间保留；进入世界的加载页不受此项影响。

## 已确认的六段

| 资源 ID | 动画 |
|---|---|
| `s1e02_01` | 第一季第 2 集，三角形 |
| `s1e02_02` | 第一季第 2 集，菱形 |
| `s1e02_03` | 第一季第 2 集，圆圈与 @ |
| `s1e02_04` | 第一季第 2 集，圆圈、箭头与圆环 |
| `s1e07_01` | 第一季第 7 集，`(^o^)` |
| `s1e07_02` | 第一季第 7 集，`(≧▽≦)` |

每轮将六段随机洗牌，一段播完再播下一段，每轮六段都会出现，轮次之间也避免连续重复；片段切换有 180ms 过渡，跟随「自然过渡」开关。
加载完成后停止抽取新片段，跟随原版淡出，不等待片段播完；重载、切换界面时释放音轨和纹理。
每段保留自己的原音，统一使用音效开关和音量设置，同时跟随 Minecraft 主音量；启动期间声音使用系统默认音频输出。

## 资源与维护

- 来源：[《小林家的龙女仆》第一季幕间整理页](https://yottyanikadesuyo.wordpress.com/2021/07/07/%E3%80%90pb%E3%82%A2%E3%82%A4%E3%82%AD%E3%83%A3%E3%83%83%E3%83%81%E3%83%B3%EF%BC%81%E3%80%91%E5%B0%8F%E6%9E%97%E3%81%95%E3%82%93%E3%81%A1%E3%81%AE%E3%83%A1%E3%82%A4%E3%83%89%E3%83%A9%E3%82%B4%E3%83%B3/)，用户已逐段确认选择；素材权利归原权利人，项目源码许可证不包含对这些素材的额外授权。
- `assets/yachiyoc/loading/originals/` 保留全部六份原始 WebM，`manifest.json` 记录来源、SHA-256、尺寸和帧时间；运行时只使用 PNG 图集与 PCM WAV，不请求网络、不加载视频解码器。
- 图集保留原动画时间，合并重复停留帧和轻微编码噪声；符号用透明度蒙版绘制，图集不超过 2048×2048，同时最多缓存两张。
- 重新制备素材：`uv run --with av --with pillow tools/prepare_loading_assets.py`；使用已有原片，不读写 `run/`。先完成资源制备，再执行离线构建。
- `--debug loading true` 打开播放/回退日志。资源有误时回退原版加载页；音频设备不可用时继续无声播放动画。

本轮通过 837 项素材、播放时间、随机轮播和挂载点检查，以及独立 Fabric Knot 的实际 Mixin 应用验证；没有启动 Minecraft 主程序，游戏画面和实际扬声器播放仍待验收。
