# 名字标签参考与使用

参考只用于可读性与信息层次，没有复制外部项目的代码、图片或字体到客户端资源。

- [Wurst 官方 NameTags 文档](https://wurst.wiki/nametags)：远处可读性、大小与穿墙设置。当前标签使用视深和实际 FOV 补偿，显示范围仍由原来的范围设置控制。
- [UnlimitedNametags 作者项目与演示](https://github.com/alexdev03/UnlimitedNametags)：参考多行信息的主次关系，名字、数值和状态分区。
- [Neat 作者项目页与截图](https://modrinth.com/mod/neat)：参考名字与血条的信息层次，以及血量颜色的直观变化。

在「渲染 → 名字标签 → 布局」中，「固定屏幕大小」默认开启；整体大小仍由「缩放」控制，关闭后使用原来的世界空间缩放。
主血条始终按生命值 / 最大生命值计算，受伤后保留短暂余量再回落；金色吸收条独立显示，数值仍完整保留。
装备图标上方显示完整附魔、下方显示完整装备名，保留自定义样式，过长时换行；原来的装备开关、间距、大小和神龟判断设置仍可使用。

已完成离线构建和投影尺寸、血量动画、文本完整性、旧配置兼容检查；本轮没有启动 Minecraft，尚需游戏内验收实际画面与多人场景。
