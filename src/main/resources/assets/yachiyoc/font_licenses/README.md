# Bundled font

Only Ma Shan Zheng is bundled.

## Ma Shan Zheng / 马善政毛笔体

- Source: https://github.com/google/fonts/tree/main/ofl/mashanzheng
- License: SIL Open Font License 1.1
- File: `ma_shan_zheng.ttf`

External fonts are not bundled. Put a `.ttf` file at
`config/yachiyoc/fonts/custom.ttf` and select "External Font" in the client
config. The external font remains the user's responsibility and is not
redistributed with YachiyoC.
